Prayer Widget 1.1.1 restores live iqama times after GoPray's website redesign.

- Supports the new gopray.app prayer table and both Friday khutbah sessions, while retaining support for older GoPray pages.
- Waits for redirects and page rendering before reading times.
- Retries unavailable prayer sources automatically and shares simultaneous fetch requests.
- Clarifies that the offline badge can mean one prayer source is unavailable.

Download the Windows setup executable below, quit Prayer Widget from its tray menu, and run the installer to update. Existing installations do not support automatic app updates; this release must be installed manually.
